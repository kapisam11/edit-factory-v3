# Repository history notes

This directory contains historical engineering notes and implementation summaries from earlier iterations of AI Video Factory v2.

They are retained for context, but they are **not the source of truth for current behavior**. For current usage, architecture, deployment, testing, and supported interfaces, use the root `README.md` and the current documents under `00-INFO/`.

Some historical examples may reference files, commands, versions, or behavior that no longer exist. They are kept as project history rather than active documentation.
