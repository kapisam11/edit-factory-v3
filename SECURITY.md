# Security

## Reporting a security issue

Please do not publish exploitable security details in a public GitHub issue.

For a security report, contact the repository owner through the GitHub account
`kapisam11` and include enough information to reproduce the issue, the affected
version/commit, and the potential impact.

Do not include passwords, API keys, access tokens, or other real credentials in
a report.

Edit Factory v2 is provided on an as-is basis under the terms in [LICENSE](LICENSE).

files, generated content, and third-party service integrations.
